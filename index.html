無料版・アプリ内課金

無料で使えますか?

はい。ネタ帳3冊、カード合計30枚まで(没ネタは数えません)は無料でそのまま使えます。それ以上は、「フル機能の解除」(アプリ内課金・買い切り)が必要です。

上限を超えたら、データは消えますか?

消えません。新しいネタ帳・カードを作れなくなるだけで、閲覧・編集・コピー・削除・並べ替えは、いつでも使えます。

解除するには?

上限に達したときに出る案内画面、または設定の「フル機能の解除」から、「解除する」を押してください。

購入はiPhone・iPad・Macで共通ですか?

はい。同じ Apple ID なら、どれか1台で解除すれば、ほかの端末でも解除済みになります。ファミリー共有にも対応しています。

機種変更や再インストールで、解除が消えました。

案内画面または設定の「購入を復元」を押してください(同じ Apple ID でサインインしている必要があります)。

返金してもらえますか?

返金は Apple が受け付けています(reportaproblem.apple.com)。返金されると、解除は無効になります。

iCloud 同期

同期するには?

すべての端末で同じ Apple ID の iCloud にサインインし、iCloud Drive をオンにしてください(設定 → Apple ID → iCloud)。

同期に時間がかかります。

iCloud へのアップロードのタイミングは OS が決めるため、数十秒から数分かかることがあります。設定の「他の端末の変更を今すぐ確認」で、最新の状態を取りに行けます。

同期されません。

iCloud の保存容量がいっぱいだと、アップロードができません。設定 → Apple ID → iCloud で空き容量を確認してください(ねたはこの設定に問題があるときは警告が出ます)。

データはどこに保存されますか?

iCloud が使えるときは、iCloud Drive の「ねたはこ」フォルダ(「ファイル」アプリで見られます)に保存されます。Mac では、設定の「保存先」で別のフォルダを選ぶこともできます(その間は iCloud 同期は使いません)。

バックアップはありますか?

自動で作成されます(1時間ごと、直近10世代)。

新しい端末にデータを移すには?

同じ iCloud にサインインするだけで、自動で同期されます。ほかに、設定の「書き出し」「読み込み」(Mac は「ファイル」メニュー)でファイルとして移すこともできます。

使い方

カードを消してしまいました。

「没ネタ」ネタ帳に避難しています(「没ネタ救済」が有効のとき)。

カードの並び順が他の端末に反映されません。

カードの手動の並べ替えは、端末ごとの並びです(カードの追加・編集・削除・移動、ネタ帳の名前・色・並び順は同期されます)。
